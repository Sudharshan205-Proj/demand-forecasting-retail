BigQuery was not used: the project's database work is SQLite.

The operating environment is Windows x86-64; the pipeline also runs on
Linux/macOS, where only path separators differ.

## Individual tools

- **Python** carries the data processing, analysis, forecasting, testing and
  application development.
- **R and RStudio** carry the Phase 14 analysis and reporting. An RStudio
  project (`demand-forecasting-retail.Rproj`) sits at the repository root; the
  workflow was run from the IDE (script sourced, report knitted) and wrote 12
  files and 4 figures to `data/analysis/r/`, passing 91 of 91 quality checks.
  The RStudio IDE version is not machine-readable from the command line.
- **SQLite** backs the Phase 4 relational schema and the 18 analytical queries.
- **Tableau Public** holds the published dashboard at
  <https://public.tableau.com/views/Retail_Demand_Forecasting/RetailDemandForecastingInventoryPlanning>.
  The workbook records its own `source-build` (`2026.2.2`); the installed client
  version is not read from the command line.
- **Spreadsheets** — the Phase 3 workbook is generated by
  `scripts/create_spreadsheet_analysis.py`; the workbook opens and validates, but
  the local spreadsheet application version is not recorded.

## Python environment

The project uses a local `.venv`. `.python-version` pins Python 3.12 and
`pyproject.toml` declares `requires-python = ">=3.11"`.

Dependencies are pinned in `requirements.txt`:
numpy 2.5.2, pandas 3.0.5, matplotlib 3.11.1, scipy 1.18.1, scikit-learn 1.9.0,
statsmodels 0.15.0, streamlit 1.63.0, openpyxl 3.1.5, jupyter 1.1.1, pytest
9.1.1. Analysis output depends on these versions.
