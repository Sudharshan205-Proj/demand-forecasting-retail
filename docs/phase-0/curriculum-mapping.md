# Curriculum-to-Project Mapping

## Purpose

This document is the row-by-row record of how the Demand Forecasting for Retail
project applies the internship course material. It is the authoritative mapping
behind [`../course-coverage.md`](../course-coverage.md).

A topic counts as covered only when project evidence exists; a topic that
appears in the course but has no applicable project component is recorded as
not applicable rather than omitted.

## Status definitions

- ⬜ Not evident
- 🟨 Partial — documented and reasoned about, not exhaustively evidenced
- 🟩 Evidenced
- 📄 Documented
- ❌ Not applicable to this project

## Six-stage methodology

| Stage | Retail project application | Status |
|---|---|---|
| Ask | Define the retail demand problem, stakeholders, objectives and SMART questions | 🟩 |
| Prepare | Acquire and understand sales, promotion and product data | 🟩 |
| Process | Clean, validate, transform and integrate the data | 🟩 |
| Analyze | Perform spreadsheet, SQL, Python, R, statistical and forecasting analysis | 🟩 |
| Share | Tableau, charts, reports and storytelling | 🟩 |
| Act | Forecast demand and produce inventory recommendations | 🟩 |
