# Course Coverage

How the eight internship courses are demonstrated by this project. This is the
master index: the authoritative, row-by-row mapping is
[`phase-0/curriculum-mapping.md`](phase-0/curriculum-mapping.md), and each
technical phase carries its own `course-content-coverage.md`.

Coverage claims follow one rule: **a topic counts as covered only when project
evidence exists.** The mapping uses four statuses — evidenced, documented but not
exhaustively verified, not evidenced, and not applicable.

## Scope decisions

These are recorded rather than worked around, following the curriculum rule that
a technique is added only when the project needs it.

| Topic | Status | Reason |
|---|---|---|
| Holidays | Not applicable | Phase 2 confirmed an explicit holiday variable is absent from the dataset; the requirement was conditional on availability |
| Prophet / LSTM | Not applicable | Both were assessed and deliberately not implemented; the assessment is the recorded evidence, and the delivered model set is ARIMA plus the feature-based gradient-boosting candidate |
| Temporary tables (SQL) | Not applicable | The analysis uses common table expressions; introducing temporary tables only to claim coverage is explicitly discouraged |
| Data bias, qualitative data, collaboration, normalization, data governance, access control, ownership, consent, correlation visualization, annotations | Documented but not exhaustively verified | Reasoned about and recorded in the relevant phase documents; not claimed as fully verified. Accessibility is not in this row: the human usability and accessibility review of the rendered interface is complete |

The row-by-row status for every curriculum topic is in
[`phase-0/curriculum-mapping.md`](phase-0/curriculum-mapping.md).
