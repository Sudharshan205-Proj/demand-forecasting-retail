# Project Requirements

## 1. Project

Demand Forecasting for Retail

## 2. Primary Goal

Forecast product demand to support inventory planning and optimization.

## 3. Mandatory Retail Requirements

The project must:

1. Use historical sales data.
2. Include promotions where available.
3. Include holidays where available.
4. Use time-series forecasting.
5. Implement ARIMA.
6. Implement or evaluate an additional permitted forecasting approach where justified:
   - Prophet
   - LSTM
7. Evaluate forecasts using:
   - RMSE
   - MAPE
8. Compare forecasting approaches.
9. Produce future demand forecasts.
10. Translate forecasting results into inventory-related insights.
11. Provide a usable application.
12. Deploy the application using a reproducible process.
