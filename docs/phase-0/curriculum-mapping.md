## Final Audit Rule

Every item must eventually answer:

1. Was it taught?
2. Is it relevant?
3. Where is it implemented?
4. What is the evidence?
5. Is it complete?
6. If not, why?
7. Does the implementation genuinely demonstrate the concept?

Documentation alone is not sufficient evidence.
